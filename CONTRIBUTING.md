# Contributing to Minecraft VFX Site

Thank you for your interest in contributing! Here's how you can help.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR-USERNAME/minecraft-vfx-site.git`
3. Create a branch: `git checkout -b feature/your-feature`
4. Make your changes
5. Push to your fork and submit a pull request

## Code Style

- Use 2-space indentation
- Keep lines under 80 characters where possible
- Use meaningful variable names
- Add comments for complex logic
- Follow existing code patterns
- Use Pixelify Sans font for text elements when applicable

## Types of Contributions

### 🐛 Bug Reports
- Describe the issue clearly
- Include steps to reproduce
- Specify browser and OS
- Add screenshots if applicable

### ✨ Features
- Discuss in an issue first
- Keep features focused and modular
- Add documentation
- Test across browsers
- Add click VFX if it's an interactive element

### 📚 Documentation
- Improve README clarity
- Add code comments
- Create usage examples
- Fix typos and errors

### 🎨 Design Improvements
- Maintain Minecraft aesthetic
- Keep purple/blue/black theme consistency
- Ensure mobile responsiveness
- Keep accessibility in mind
- Test on various devices

### 🎬 VFX Enhancements
- Add new particle effects
- Improve animation performance
- Create new click animations
- Optimize canvas rendering
- Maintain frame rate performance

## Pull Request Process

1. Update documentation with any changes
2. Test on multiple browsers
3. Ensure responsive design is maintained
4. Add descriptive commit messages
5. Reference any related issues
6. Verify VFX performance (target 60 FPS)

## Design Philosophy

- Keep it minimal and clean
- Prioritize performance (60 FPS)
- Maintain Minecraft aesthetic
- Ensure accessibility
- Purple/Blue/Black theme consistency
- No external dependencies when possible
- Every interactive element should have satisfying VFX

## VFX Guidelines

When adding new interactive elements:
- Include click VFX (block break and/or hit particles)
- Test performance with multiple clicks
- Ensure particles don't overlap with important UI
- Use theme colors: #7c3aed, #3b82f6, #a78bfa
- Keep animation duration 0.5-0.8 seconds

## Questions?

Feel free to open an issue for discussion before submitting large changes.
